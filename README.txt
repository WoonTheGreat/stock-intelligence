STOCK INTELLIGENCE V1 - LOCAL

EASIEST:
Double-click index.html to open the dashboard in Chrome, Safari or Edge.

OPTIONAL LOCAL SERVER:
1. Open Terminal/Command Prompt in this folder.
2. Run:
   python3 -m http.server 8000
3. On the same computer open:
   http://localhost:8000

PHONE:
If your PC and iPhone are on the same Wi-Fi, find the PC's local IP address and open:
   http://YOUR-PC-IP:8000
on the iPhone.
